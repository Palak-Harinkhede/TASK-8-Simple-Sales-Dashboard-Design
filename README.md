# Task 8: Simple Sales Dashboard

## Overview
This project is part of the Data Analyst Internship Task 8, where I built an interactive sales dashboard using Power BI to visualize sales performance by product, region, and month.

## Dataset
I used the provided `cleaned_superstore (1).csv` dataset, which contains sales records with details like:
- Order Date
- Region
- Category
- Sales
- Profit

## Tools Used
- Power BI Desktop

## Dashboard Features
- **Line Chart:** Sum of Sales by Month-Year
- **Bar Chart:** Sum of Sales by Region
- **Donut Chart:** Sum of Sales by Category
- **Slicers:** Interactive filters for Region and Category

## Key Insights
- Central region leads all regions with ~2.8M in sales.
- Technology category accounts for ~37.5% of total sales.
- Sales show strong monthly growth, with peaks in June and September.
- Filtering by region or category highlights performance differences across segments.
